# Phase 0 기술 검증

앱의 **기록 탭 → 개발자 → 기능 검증 랩**에서 진행한다. 코드와 빌드는 준비됐고, 실제 폰 시험만 남았다.

## 확인 상태

| 항목 | 에뮬레이터 결과 | 실제 폰 |
|---|---|---|
| 빌드, 단위 테스트 6개 | 통과 | 해당 없음 |
| 앱 실행 | 충돌 없음 | 미확인 |
| TTS 영어 억양 | en-US 설치됨, en-AU, en-GB, en-IN, en-NG는 미설치로 표시 | 미확인 |
| TTS 미설치 음성 재생 | `setVoice`와 `speak`는 성공 코드를 돌려줌, 실제 소리는 미확인 | 미확인 |
| 온디바이스 STT | 지원 언어 en-US, AU, GB, IE, SG, CA, IN. 언어팩 다운로드는 `ERROR_CLIENT`로 실패해 인식 자체는 시험 못 함 | 미확인 |
| 녹음과 인식 동시 | 언어팩 없음 오류를 표시하고 앱은 유지, WAV 파일 생성 | 미확인 |
| Gemma 모델 다운로드 | 일시정지와 이어받기 동작(35MB → 78MB), 전체 다운로드는 안 함 | 미확인 |
| Gemma 로드, 채점, 음성 입력 | 시험 불가(에뮬레이터 RAM 2.4GB, 저장공간 4.3GB) | 미확인 |

모델은 로그인 없이 받을 수 있다: 비공개 제한 없음, Apache-2.0, 2,588,147,712바이트.

## 폰에서 시험할 순서

1. **억양:** 음성 설치 → 영국, 호주, 인도, 나이지리아 음성 받기 → 다시 확인 → 각각 듣기.
2. **영어 읽기 실험:** es-US, hi-IN 음성으로 영어 문장 듣기. 억양 훈련에 쓸 만한지 귀로 판단한다.
3. **음성 인식:** 지원 확인 → 영어팩 받기 → 일반 인식 → 녹음과 인식 동시 → 내 녹음 듣기. 비행기 모드에서 한 번 더.
4. **Gemma:** 모델 받기(Wi-Fi) → GPU 로드 → 채점 테스트 → 음성 입력 테스트. GPU가 실패하면 CPU 로드.
5. **결과 전체 복사**로 결과를 전달한다. USB로 연결돼 있으면 logcat 태그 `PHASE0`로도 읽을 수 있다.

## 판단 기준

| 시험 | 합격 | 불합격 시 |
|---|---|---|
| 일반 인식 | 또렷이 읽었을 때 일치 80% 이상 | 언어팩 재시도 후 온라인 인식 허용 검토 |
| 녹음과 인식 동시 | 결과와 들을 수 있는 녹음이 함께 남음 | 쉐도잉에서 "녹음"과 "인식 채점"을 별도 시도로 분리 |
| Gemma 채점 응답 | 전체 30초 이내, 좋은 답변이 나쁜 답변보다 높은 점수 | AI는 선택 기능으로 낮추고 부분 채점 위주 |
| Gemma 음성 입력 | 내용을 대체로 맞게 받아 적음 | 텍스트 채점만 사용 |

## 억양 음성 출처 조사

| 억양 | 1순위 출처 | 라이선스 | 확인 상태 |
|---|---|---|---|
| 미국, 영국, 호주, 인도, 나이지리아 | 기기 TTS(Google) | 기기 내장 | 목록은 에뮬레이터에서 확인, 소리는 폰에서 확인 필요 |
| 인도(자연스러운 대화) | EdAcc | CC BY-SA | 대화 데이터 확인, 20~60분 녹음이라 잘라야 함 |
| 나이지리아, 케냐, 탄자니아, 남아공, 필리핀, 싱가포르 | Azure 신경망 음성 | 아래 주의 참고 | 로케일 확인 |
| 필리핀, 싱가포르, 남아공, 인도(짧은 문장) | GLOBE | CC0 | 확인 |
| 남미(스페인어권) | Speech Accent Archive | CC BY-NC-SA 4.0 | 실제 녹음 222개 확인, 단 같은 문단 하나를 읽은 것 |
| 남미(TTS 보조) | Azure es-MX 음성의 영어 읽기 | 아래 주의 참고 | 억양 품질 미확인, 귀로 판단 필요 |

**주의**
- Azure 무료 등급은 월 50만 자로 공식 확인했다. 하지만 생성한 음성의 저장 권리가 유료 등급에만 해당한다는 Q&A 인용이 있고 약관 원문은 확인하지 못했다. Azure를 쓰기로 하면 먼저 약관을 확인한다.
- 비영리(NC) 라이선스는 개인 앱에 맞아 보이지만 법률 판단은 아니며, 앱을 공개하려면 다시 검토해야 한다.
- 남미 억양의 자연스러운 대화 음성은 아직 찾지 못했다. EdAcc에 남미 화자가 있는지 미확인이다.
